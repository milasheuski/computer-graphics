# Компьютерная графика

Лабораторные работы на Python и Streamlit. Каждая работа размещена в отдельной ветке.

| Ветка | Тема | Основной файл |
|---|---|---|
| [lab1](https://github.com/milasheuski/computer-graphics/tree/lab1) | Цветовые модели | `app.py` |
| [lab2](https://github.com/milasheuski/computer-graphics/tree/lab2) | Чтение информации об изображениях | `app.py` |
| [lab3](https://github.com/milasheuski/computer-graphics/tree/lab3) | Обработка изображений | `app.py` |

## Запуск

Переключитесь на ветку нужной лабораторной, установите зависимости и запустите приложение:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Для публикации в Streamlit Community Cloud выберите этот репозиторий, ветку нужной работы и файл `app.py`.

Текущие версии файлов перенесены из `ColorConverter_Lab`, `pkg_lab_2` и `lab3`. История разработки сохранена в исходных репозиториях.
